# KSEL Touch

Форк [KSEL](https://github.com/fourchinthehouse/KSEL-Launcher) (автор — fourchinthehouse, основан на
[MonoLaunch](https://github.com/monobogdan/monolaunch) от monobogdan, MIT).
Лаунчер в стиле меню кнопочных телефонов 2000-х, теперь **с поддержкой сенсорного экрана**.
Управление клавишами (D-pad, софт-клавиши, цифры) полностью сохранено — это универсальная сборка.

## Что нового

### Сенсорное управление
| Жест | Действие |
|---|---|
| Тап по иконке | запуск приложения |
| Свайп влево / вправо в меню | следующая / предыдущая страница |
| Свайп вверх на главном экране | открыть меню (тап по экрану — тоже) |
| Свайп вниз на главном экране | шторка уведомлений |
| Свайп вниз в меню | назад на главный экран |
| Тап по нижней полосе | левая / правая софт-клавиша (по подписям) |
| Тап по строке в настройках | переключить пункт |
| Перетаскивание в списке приложений | прокрутка |
| Свайп вправо в настройках | назад |
| Долгое нажатие | настройки лаунчера (как клавиша MENU) |

На устройствах с тачскрином системная кнопка «Назад» на главном экране больше не открывает контакты
(на кнопочных телефонах это правая софт-клавиша, поведение там прежнее).

### Оптимизация
- Настройки больше не читаются из `SharedPreferences` 3–4 раза на каждый кадр — кэш, обновляется при изменении.
- Список приложений: сначала дешёвая проверка (сигнатура компонентов), и только если набор изменился —
  загрузка названий/иконок. Иконки рисуются сразу в фоновом потоке в нужном размере; `Drawable` не хранятся
  (меньше памяти). Устаревшие результаты отбрасываются.
- Исправлена потенциальная порча общих иконок (`recycle()` чужого `Bitmap`).
- Когда ничего не движется — перерисовка 25 кадров/с (фоновое «дыхание»), в режиме без анимации — 1 кадр/с.
- Убраны аллокации строк в `onDraw` (номера клавиш, индикатор страниц), диагностические проходы по списку.
- Звук: настройки кэшируются; `SoundPool` пересоздаётся после detach (раньше звуки пропадали после нажатия HOME).
- Обои декодируются только при смене (broadcast + страховочное обновление раз в 5 мин), а не при каждом `onResume`.
- `setContentView` не вызывается повторно при возврате на главную (раньше view отсоединялся и терял ресурсы).
- Исправлено: переключение 12/24 ч применялось только со следующей минуты.
- Системная «Назад» не закрывает лаунчер.

## Сборка (без Gradle)
Нужны: `openjdk-jdk`, `aapt`, `dalvik-exchange`, `zipalign`, `apksigner`, `libandroid-23-java`
(пакеты Debian/Ubuntu; на Arch — Android SDK build-tools + любой `android.jar`, путь задаётся `ANDROID_JAR`).

```bash
./build.sh            # -> build/KSEL-Touch.apk
```
Ключ подписи создаётся автоматически в `keystore/` (в git не попадает). Для релиза используйте свой ключ:
`KEYSTORE=/path/my.jks ./build.sh` (пароли в скрипте — `android`, поменяйте под себя).

## Установка
Установить APK, нажать «Домой» и выбрать **KSEL Touch** лаунчером по умолчанию.
Требуется Android 4.1 (API 16)+. Пакет: `com.kseltouch.launcher` (установится рядом с оригинальным KSEL).
