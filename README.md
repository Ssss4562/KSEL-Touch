# KSEL

***Идеально заточен под CTYON CT07***

Лаунчер для Android в стиле меню Популярных Кнопочников 2000-х. Рассчитан на **кнопочные телефоны без тачскрина**: всё управляется клавиатурой, интерфейс рисуется целиком на `Canvas` с анимациями, звуками и вибрацией.


## Возможности

- **Главный экран** с часами, датой, строкой статуса и софт-клавишами (левая/правая).
- **Меню приложений** в виде сетки с постраничной прокруткой и индикатором страниц.
- **Быстрый переход по цифрам** `1–9`, `0`, `*`, `#` к нужной ячейке сетки (номера можно показывать на иконках).
- **Список запущенных приложений** и индикатор свободной памяти (MB available).
- **Скрытие приложений** из меню и режим «Show all».
- **Анимации** с несколькими уровнями (Full / Reduced / Off): плавное перемещение рамки выделения, анимированные переходы между экранами, эффект запуска приложения, отражения и свечение.
- **Фон:** обои системы или тёмный фон, автоматическая подстройка оформления под яркость обоев.
- **Часы:** 12/24-часовой формат.

## Управление

| Кнопка | Действие |
| --- | --- |
| D-pad | перемещение по сетке |
| Центральная / левая софт-клавиша | выбор, запуск |
| Правая софт-клавиша | назад |
| `MENU` | настройки |
| `CALL` | звонилка |
| `1–9`, `0`, `*`, `#` | переход к ячейке сетки |

## Настройки

Раздел **KSEL Settings** (открывается по `MENU`):

- Animation: Full / Reduced / Off
- Sounds
- Vibration
- Background: Wallpaper / Dark
- Show numbers
- Clock (12/24 ч)
- Applications: выбор скрытых приложений
- Launcher: выбор лаунчера по умолчанию

## Требования

- Android 4.1 (API 16) и выше
- Физическая клавиатура / D-pad (тачскрин не требуется)

## Установка

1. Скачай APK из раздела [Releases](../../releases).
2. Разреши установку из неизвестных источников.
3. Установи APK и выбери **KSEL** в качестве приложения «Домой» по умолчанию.

> Текущая сборка — `debug`.
